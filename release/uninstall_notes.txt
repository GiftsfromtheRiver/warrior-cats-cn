《猫武士：森林中的族群》简体中文汉化 — 卸载说明
=================================================

汉化包不会修改游戏本体文件，只向游戏的 Paks 目录新增 3 个文件，卸载非常安全。

一、手动卸载（推荐）
1. 关闭游戏。
2. 打开游戏安装目录下的：
     <游戏安装目录>\Wrc\Content\Paks\
   例如：
     F:\SteamLibrary\steamapps\common\Warrior Cats Clans of the Forest\Wrc\Content\Paks\
3. 删除下面 3 个文件（必须 3 个一起删除）：
     pakchunk0-Windows_P.pak
     pakchunk0-Windows_P.utoc
     pakchunk0-Windows_P.ucas
4. 如果曾经手动备份过同名文件，或安装脚本生成了
   pakchunk0-Windows_P.*.wrccn-backup-<时间> 文件，可忽略或删除它们。
5. 重新启动游戏，即为原版英文。

二、用脚本卸载（安装过 Python 与 installer.py 时）
   python installer.py rollback --paks-dir "<游戏安装目录>\Wrc\Content\Paks"
   脚本会按安装记录删除汉化文件，并恢复安装时备份的同名旧文件。

三、用 Steam 验证完整性
- Steam「验证游戏文件的完整性」不会删除这 3 个额外文件；
  若要恢复纯净原版，请先按上面步骤删除这 3 个文件，再执行 Steam 验证。
- 游戏更新后，更新会覆盖原版 pak；汉化包需要重新安装（重新复制 3 个文件）即可。

四、注意事项
- 不要删除或改名原版文件：
    pakchunk0-Windows.pak / pakchunk0-Windows.utoc / pakchunk0-Windows.ucas
    global.utoc / global.ucas
- 汉化包与存档无关；卸载不会影响存档进度。
- 如卸载后仍显示中文，请确认 Paks 目录中已无上述 3 个文件，且游戏进程已完全退出后重开。
