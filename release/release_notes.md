# 发布说明 — 《猫武士：森林中的族群》简体中文汉化

- 汉化版本：`0.1.3`
- 构建日期：`2026-10-26`
- 适用游戏：Warrior Cats: Clans of the Forest（Steam，UE 5.7）

## 本次内容

1. **全文本汉化（8,901 条）**
   覆盖 `Wrc/Content/Gameplay/Strings/NonAsset/Strings_EN.csv` 的全部条目：
   主菜单 / UI 按钮 / 设置 / 任务与目标 / 对白与旁白 / 成就 / 教程提示 / 物品与技能说明 /
   图鉴与统计 / 报错与提示文本等。
   游戏运行时按 key 从该 CSV 取文本，因此这是唯一的文本来源，无需修改任何 uasset。

2. **中文字体替换（10 个 `.ufont`）**
   游戏原版字体（Catamaran / Noto Sans 拉丁版等）不含 CJK 字形，直接显示中文会变成方块。
   本汉化包覆盖为 **Noto Sans SC 子集**（OFL 许可，保留拉丁与常用简体中文字形），
   保证正文、按钮、数字与标点正常渲染。

3. **加载方式**
   通过 UE 的 patch pak 机制（文件名 `_P` 后缀，ReadOrder 高于原版）覆盖原版 pak 中的同名文件；
   不修改游戏 exe、不写入任何散落文件，可随时完整卸载。

## 安装（简述）

把 `pakchunk0-Windows_P.pak / .utoc / .ucas` 三个文件一起复制到
`<游戏安装目录>\Wrc\Content\Paks\`，或运行安装脚本：

```bat
python installer.py install --paks-dir "<游戏安装目录>\Wrc\Content\Paks" --mod-dir .
```

详细步骤见同目录 `README-安装说明.md`。

## 卸载

删除 `Paks` 目录下的 3 个文件即可（或 `python installer.py rollback --paks-dir <Paks>`）。
详细步骤见同目录 `uninstall_notes.txt`。

## 已知限制

- **语音仍为英文**：对话语音（VO）未替换；字幕/对白文本已汉化。
- **贴图内嵌英文不翻译**：直接画在 UI 贴图/美术字里的英文（部分图标文字、标题美术）无法通过文本表翻译，
  如需汉化需替换贴图，不在本次范围内。
- **游戏语言设置保持 “English”**：本汉化包替换的是 EN 语言槽位的文本文件，因此游戏内语言请保持 English，
  此时界面显示的即为中文；切成其他语言会加载对应原文 CSV（仍为外文）。
- **制作人员名单保留原文**：143 条 `STR_CREDITS_*` 姓名/职位按惯例保留英文（避免译名歧义）。
- **字体**：中文排版使用 Noto Sans SC 子集替换原版拉丁字体（OFL 许可，覆盖全部译文用字 + 拉丁字符/数字）；
  个别特殊符号若显示异常请反馈。
- **引擎/调试界面**：沙盒、作弊、控制台等开发用菜单中的英文未汉化（正常游戏流程不可见）。
- 联机/成就：本汉化仅修改本地文件，不改变存档与云存档；请自行评估使用第三方汉化包的账号风险。
